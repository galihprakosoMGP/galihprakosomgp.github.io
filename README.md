# Portfolio Website

Personal front-end portfolio built with HTML, CSS and JavaScript (no framework, no build step).

**Live site:** https://galihprakosomgp.github.io/

## Projects
| Project | Description | Demo | Code |
|---|---|---|---|
| E-Commerce | Shopping site with cart, checkout and owner dashboard (LocalStorage) | [Demo](https://galihprakosomgp.github.io/e-commerce/) | [Code](e-commerce) |
| Weather App | Live weather from the Open-Meteo API with animated themes | [Demo](https://galihprakosomgp.github.io/weather-app/) | [Code](weather-app) |
| Expense Tracker | Track income and expenses with charts and printable reports | [Demo](https://galihprakosomgp.github.io/expense-tracker/) | [Code](expense-tracker) |
| Landing Page | Responsive, conversion-focused product landing page | [Demo](https://galihprakosomgp.github.io/landing-page/) | [Code](landing-page) |

## Structure
```
index.html, style.css, script.js   portfolio home page
e-commerce/  weather-app/  expense-tracker/  landing-page/   one folder per project (each has its own README)
```

## Run locally
Open `index.html` in a browser (internet needed for CDN fonts/libraries and the weather API).

## Note
The e-commerce demo stores data only in each visitor's browser. Its owner PIN (`1234`) is a public demo value.
